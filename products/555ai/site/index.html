开始之前，你可能想了解

需要先注册账号吗？

使用 hiAi 平台模型时，请在客户端完成账号登录；也可以使用“添加 API Key”配置自己的模型服务。

可以更换默认模型吗？

可以在客户端选择可用模型。平台模型列表由管理员配置；自己接入的服务以对应 API Key 和模型配置为准。

下载后为什么版本仍标为预览版？

产品与插件仍在持续完善，功能和界面可能调整。安装包版本、文件大小与校验值会随每次发行更新。

__PRODUCT_NAME__ 与 DeepSeek Harness 是什么关系？

__PRODUCT_NAME__ 是基于开源 DeepSeek Harness 构建的独立发行版本，使用自己的名称、图标和 hiAi 账号服务，并非 DeepSeek 官方客户端。开源许可及第三方声明保留在安装包中。
